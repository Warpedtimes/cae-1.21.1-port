## Client extras (quality of life)

These only run on your own computer. You can play on a server without them being on the server.

| Mod | What it does |
|---|---|
| Particle Rain | Rain and snow made of particles, for a punchier look. |
| Ok Zoomer | A zoom key. Default key on a fresh install: the key under Escape (`). |
| Full Brightness Toggle | A key that turns full brightness on and off. Default key on a fresh install: N. |
| Iris Shaders and Sodium | Shaders and the renderer. They replace Oculus and Rubidium or Embeddium. |
| Custom Window Title, Swing Through Grass | In the original pack; brought back. |

You can change all keys in **Options, Controls, Key Binds**.

## Maps

| Mod | What it does |
|---|---|
| Xaero's Minimap | The minimap. On a server it also shows other players on the map. |
| Xaero's World Map | The big map. |
| Xaero's Maps: Multiplayer+ | Shares explored map tiles between players through the server. Players without it can still join. |

Xaero's mods must be the **same version** on the server and on every client. Do not add your own copies.

## Continued versions of old mods

These mods stopped at an old version. Another project carries each one on, and the pack uses that one:

- Construction Wand: KOTS (Construction Wand)
- Decorative Blocks Reborn (Decorative Blocks)
- Glassential Renewed (Glassential)
- Immersive Weathering: Renewed (Immersive Weathering)
- Steam 'n' Rails (NeoForge) (Create: Steam 'n' Rails)
- Amendments: Supplementaries moved wall lanterns, skull piles, candles, ceiling pots and banners into this mod.
- Modern Train Parts: in the original pack, and brought back.
- Forgified Fabric API: Do a Barrel Roll needs it on NeoForge.

## Libraries

Some mods are only here because another mod needs them. Examples are Athena, AzureLib, CraterLib, GlitchCore, GuideME,
KilaGraph, Kotlin for Forge, Melody, Resourceful Lib, Searchables, YetAnotherConfigLib and Zeta. They add nothing you
use directly.
